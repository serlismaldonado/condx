Agents

A team that works on branches, not on your main

Each agent has one job. Ask in plain words, or mention one with @. Writers work in their own copy of the repo and push a branch; readers only read.

Fixer

Makes the change, runs your checks and commits to its branch.

Reviewer

Reads the exact diff and approves it or asks for changes.

Triage and Risk

Find where an error comes from and how urgent it is.

Phone

Your agents in your pocket

The Android app talks to your Mac, or to the cloud when the Mac is off. Every message and approval is signed with a key that never leaves the phone.

Threads with every agent

Reply to a message and it goes to whoever wrote it. Type @ to bring in someone else.

Approvals

Deploys, releases and merges wait for you. Approve from the phone; production asks for Touch ID on the Mac.

See changes

The files and the diff of an agent's branch, right under its reply, before you merge.

Voice notes

Talk instead of typing. Transcribed on your Mac with Whisper; no keys, the audio stays home.

Photos and files

A screenshot of the bug, a log, a PDF. Agents that see images read them.

Notifications

Replies, incidents and approvals, as push and in the app. Tap one to open its thread.

Android, early access. Updates arrive in the app with an Install button.

Cloud

Close the laptop. The work keeps going.

Condx Cloud runs on your own Convex deployment and mirrors your Mac. When the Mac is off (or you choose the cloud in the phone), a cloud worker answers instead.

Threads, tasks and previews

The same agents and flows, against each project's cloud dev, with a URL to try the result.

Merge to dev from anywhere

Branches go to GitHub with your token; merging is one slide in the phone.

Releases without the Mac

The desktop app and the phone app build and publish on GitHub Actions, and update themselves.

Claude, from anywhere

A remote MCP server: connect Claude once with a code from your phone, and give tasks with the Mac off.

Safety

Agents do the legwork. You keep the keys.

The same rules for Condx's agents and for yours (Claude Code, Cursor, Codex) through the MCP server. Logs, files and messages from outside are data, never orders.

Install

Up and running in a few minutes

macOS 15+ on Apple Silicon, with Node.js and the Convex CLI in your projects. The app walks you through the first launch.

1Install the app and the daemon

Condx.app plus condxd, the daemon that runs in the background.

curl -fsSL https://condx.vercel.app/install.sh | bash

2Add your Convex projects

Or let the app find them in a folder.

~/.condx/daemon/bin/condxd project discover ~/code
~/.condx/daemon/bin/condxd project add ~/code/my-app

3Connect your coding agent

Claude Code, Cursor, Codex: they see what Condx sees and ask for jobs.

# Claude Code
claude mcp add condx -- ~/.condx/daemon/bin/condxd mcp

4Optional: phone and cloud

Deploy Condx Cloud to your own Convex project, then pair the phone with the QR in the app.

git clone https://github.com/serlismaldonado/condx.git
cd condx && scripts/cloud-deploy.sh
