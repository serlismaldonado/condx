03 Features

Everything around your backend

What lives outside your editor, in one place.

Data, in every environment

Tables with counts, paging, relations and the document beside them.

  • Read-only; production hidden by default
  • Double-click an _id to copy it

Workflows you can trust

Checks, approvals and deploys in a chain. Agents start them; you approve.

  • Turn them on and off
  • Retry from the failed node

Jobs and approvals

Deploys, backups, rehearsals and functions, each with its log.

  • Touch ID for production

05 Install

Start in two commands

macOS 15+, built from source with Rust. Homebrew soon.

git clone https://github.com/serlismaldonado/condx.git
cd condx && cargo build --release

# The daemon (launchd) and the app
./target/release/condxd install
scripts/bundle-app.sh && open ~/Applications/Condx.app
